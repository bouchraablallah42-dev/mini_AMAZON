# Mini Amazon - C++

Programme de e-commerce simple en C++ qui s'exécute dans le Terminal.

## Ce que fait le programme
Il vous permet de créer un compte, parcourir les produits, ajouter au panier, acheter et consulter vos achats.

## Comment l'exécuter

1. Compilation:
g++ main.cpp -o mini_amazon

2. Exécution:
./mini_amazon
Sur Windows: mini_amazon.exe

## Mode d'emploi étape par étape

1. Écran principal:
- 1: Créer un compte
- 2: Se connecter  
- 3: Quitter

2. Après connexion:
- 1: Voir les produits et acheter  
- 2: Voir le panier  
- 3: Voir l'historique des achats  
- 4: Se déconnecter

3. Dans la liste des produits:
Choisissez le numéro du produit pour l'ajouter au panier.  
Ensuite allez dans le panier pour confirmer l'achat.

## Prérequis
- Compilateur g++
- C++11 ou supérieur
